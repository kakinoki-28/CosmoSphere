# プログラムの説明
CosmoSphereは、Pythonで実装されたゲームプログラムです。
現在は技術デモの状態になります。

## ゲームの概要
「シューティング」×「格闘ゲーム」をテーマにした対戦型アクションゲームです。
プレイヤーは、ジャンプしたり跳ねたりする丸いキャラクターに乗って操作をします。

キャラクターは豊富な「射撃スキル」と「シールド」、そして１つだけ「近接攻撃」の手段を持っています。
- **「射撃スキル」** は 「近接攻撃」 に **強い** です<br>
ダメージを食らうと攻撃動作がリセットされます。近接攻撃は振りかぶりが長いので、遠い距離で振ると格好の的になります。
- **「シールド」** は「射撃スキル」に **強い** です<br>
シールドは、射撃スキルを跳ね返したり、無効化します。射撃された弾が速ければ速いほど、反射された弾に対処できなくなります。
- **「近接攻撃」** は「シールド」に **強い** です<br>
近接攻撃は、シールドを破壊できます。ずっとシールドを構えている相手には、素早く近づいて近接攻撃をお見舞いできます。

距離を保ちつつ「射撃スキル」で勝負しても良いですし、「シールド」を上手く使って相手のミスを誘発しても良し、相手の射撃スキルをかわして「近接攻撃」で一発逆転を狙うこともできます。

格闘ゲームとはまた一味違った駆け引きを是非楽しんでください！

## 実行方法

### 実行環境
- Python 3.13.1
- pygame 2.6.1 (SDL 2.28.4)
で動作することは確認済みです。

恐らくですが
- Python 3.x
- pygame 2.6.x
であれば問題なく動作します。

### 実行手順
Python で main.py を実行してください。
main.pyに対して、「True」もしくは「False」のコマンドライン引数を与えることが出来ます。
Trueを与えるとロールバック機能の動作の様子を見ることが出来ます。

### 操作方法
デフォルトでは以下の様に操作が出来ます。

＜キーボード操作＞
- ジャンプ：W
- 左右移動：A,D
- 台から降りる：S

- 射撃スキル１：J
- 射撃スキル２：K
- 射撃スキル３：L

- 近接攻撃：Space
- シールド展開：左Shift

<コントローラー><br>
このゲームはコントローラー操作にも対応しています。<br>
コントローラーを接続すると新しくキャラが追加されます。対戦を楽しみたい場合はコントローラーを接続してください。<br>
Xbox One Controllerでの動作を確認しております。デフォルトは以下の動作です。
- ジャンプ、左右移動、台から降りる：左スティック

- 射撃スキル１：Aボタン
- 射撃スキル２：Xボタン
- 射撃スキル３：Yボタン

- 近接攻撃：Bボタン, LBボタン, RBボタン
- シールド展開：LTボタン, RTボタン
